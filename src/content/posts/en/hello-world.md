Finally got this blog up 🎉

## Why blog

Writing is practice. Code, thoughts, anime I watched, places I went — better gathered in one place than scattered.

## What's it made of

- **[Astro](https://astro.build)** — static site generator, fast builds, zero runtime JS by default
- **Tailwind CSS** + CSS variables — themes and brand color driven by CSS vars
- **GitHub Pages** — free hosting with HTTPS
- **Pagefind** — build-time search index
- **Giscus** — comments via GitHub Discussions

## Why not Hexo / Hugo

Hugo is fastest but template syntax isn't fun. Hexo has many themes but the Node ecosystem feels dated. Astro lets me:

1. Write `.astro` files (close to HTML, near-zero learning curve)
2. Drop in a React island only when interactivity is actually needed
3. Default to zero JS output
