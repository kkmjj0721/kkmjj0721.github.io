## 为什么写博客

记录是一种练习。代码、想法、看过的番剧、走过的路 —— 散落在各处的碎片不如归拢到一个地方。

## 用到了什么

- **[Astro](https://astro.build)** — 静态站点生成器，构建快、零运行时 JS（除非你显式要）
- **Tailwind CSS** + CSS 变量 — 主题/主色全部由 CSS 变量驱动
- **GitHub Pages** — 免费托管，自带 HTTPS
- **Pagefind** — 构建期生成搜索索引
- **Giscus** — 评论系统（基于 GitHub Discussions）

## 为什么不是 Hexo / Hugo

Hugo 最快，但模板语法不太顺手。Hexo 主题多，但 Node 生态老旧。Astro 让我可以：

1. 写 `.astro` 文件（接近 HTML，没有学习成本）
2. 想要互动时再「岛屿化」一个 React 组件
3. 默认输出零 JS
